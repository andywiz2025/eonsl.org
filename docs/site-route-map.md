# EON-SL canonical route map

Canonical host: `https://www.eonsl.org`

## Existing canonical pages

- `/` — homepage (`index.html`)
- `/about.html` — organization overview
- `/staff.html` — leadership and staff

## Planned public pages

- `/elections.html` — elections information
- `/observation.html` — observation methodology and field work
- `/reports.html` — reports, research, recommendations, and open data
- `/civic-education.html` — voter and civic education
- `/get-involved.html` — participation and support
- `/volunteer.html` — volunteer information
- `/observer-registration.html` — observer registration
- `/partnership.html` — partnerships
- `/contact.html` — contact information
- `/guinea.html` — Guinea presence
- `/liberia.html` — Liberia presence
- `/cote-divoire.html` — Côte d’Ivoire presence

## Canonical asset policy

- Use `assets/images/` as the only published image root.
- Use `assets/css/site.css` for shared styles.
- Use `assets/js/site.js` for shared progressive enhancement.
- Do not add pages below `assets/`.
- Keep `assets/staff.html` out of navigation and sitemap while it is being archived.

Before publishing the planned pages, verify every route exists, add it to `sitemap.xml`, and run an internal-link check.
